# HUMANIZER.md

Skill for writing any user-facing copy on this site (headlines, subtext, meta tags, alt text, error messages). Applies to English copy in a SpaceX-mission-briefing tone, football-fantasy themed.

## Goal
Every line should read like a person wrote it under a deadline for a bold brand — not like an LLM's default output. No corporate filler, no hedging, no obviously-templated phrasing.

## Checklist before shipping any copy

1. **No AI tells.** Avoid: "In today's fast-paced world," "unleash," "elevate your," "seamless," "game-changing," "dive into," "delve," em-dash-heavy listy sentences, "Furthermore/Moreover/Additionally" as sentence openers.
2. **Vary sentence length.** Mix short punchy fragments ("T-MINUS. LOCKED IN.") with one longer sentence per block. Uniform mid-length sentences are the biggest tell.
3. **Concrete over abstract.** "KICKOFF WINDOW CLOSES 17:00" beats "an exciting moment is approaching."
4. **No perfectly parallel lists.** Real writers don't make every bullet the same grammatical shape. Break the pattern occasionally.
5. **Commit to a voice and don't over-explain it.** Mission-control deadpan + football swagger. Say the thing once, don't restate it softer right after.
6. **Cut the safety hedges.** No "might," "could potentially," "in some cases" — the brand voice is confident and terse.
7. **One idea per line on display type.** Headlines are not sentences; they're transmissions.
8. **Read it out loud test.** If it sounds like a press release nobody would actually say, rewrite it.

## Reference phrasing pool (adapt, don't reuse verbatim every time)
- T-MINUS / COUNTDOWN / LAUNCH WINDOW / STATUS / HOLD / GO FOR KICKOFF / MISSION CLOCK
- Keep numerals and codes uppercase and terse, matching `DESIGN.md` display type rules (uppercase, wide tracking).

## What NOT to do
- Don't explain the joke or the theme to the reader.
- Don't add disclaimers or meta-commentary in the copy itself.
- Don't translate mid-sentence — this pass is pure English only (Bangla content is a separate future track, not part of this build).
